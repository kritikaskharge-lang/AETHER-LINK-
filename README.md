# AetherLink

## 📌 Overview
AetherLink is an offline emergency communication system that enables users to send and receive text messages using ESP32 and LoRa technology without requiring an internet connection or cellular network.

## ✨ Features
- Offline communication
- Long-range messaging using LoRa
- OLED display for messages
- LED and buzzer notifications
- Low power consumption

## 🔧 Components Used
- ESP32
- SX1278 LoRa Module
- OLED Display
- Buzzer
- LED
- Breadboard
- Jumper Wires

## ⚙️ Working
1. User enters a message.
2. ESP32 transmits it using the SX1278 LoRa module.
3. The receiving ESP32 receives the message.
4. The message is displayed on the OLED.
5. The LED and buzzer alert the user.

## 🎯 Applications
- Disaster management
- Emergency communication
- Rural communication
- Trekking and camping
